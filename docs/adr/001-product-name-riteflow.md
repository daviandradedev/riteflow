# ADR 001 - Product name: Riteflow

## Status

Accepted

## Context

The first build shipped as Sprint Report (CSV → HTML/PDF). The product vision expanded to an evidence-first ceremony OS. A report-only name undersells Ceremony and Loop and collides with a crowded “sprint report” keyword market.

## Decision

Brand the product **Riteflow** (*rite* = ceremony, *flow* = board flow signals). Keep a single app and domain (`riteflow.daviandrade.dev`). Evidence remains a module, not a separate product.

## Consequences

Clearer international positioning. Hub card and package name follow Riteflow. Old “Sprint Report” copy is retired in UI.
